# 安居算 · 房贷计算器

支持苏州与全国参考利率、商业贷款、公积金贷款、组合贷款、等额本息与等额本金比较，以及逐月还款明细。

## GitHub Pages

本项目为纯静态应用，不需要安装依赖或配置密钥。将本压缩包内文件放入仓库根目录，在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 /(root)，保存即可。

页面使用相对资源路径，兼容 GitHub Pages 的仓库子路径。

## 本地运行

在文件所在目录运行 `python3 -m http.server 8080`，然后访问 http://localhost:8080 。请通过 HTTP 服务打开，避免 file:// 对 JavaScript 模块的限制。

## 利率与计算口径

资料核验日期：2026-09-19。页面内附官方资料链接。全国 LPR 是定价基准，苏州 3.05% 是官方公告中的特定合同示例，不代表统一新贷报价。二套公积金按政策下限测算，实际年利率可手动填写。

按输入年利率在整个贷款期限内不变进行测算；不含首付、税费、保险和提前还款。组合贷的两部分采用相同期限及还款方式。输入数据仅在浏览器内计算，不上传服务器。
